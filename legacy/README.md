# Retired Setup

The archived bootstrap preserves the pre-migration setup, including preexisting
local edits. It is not used by `setup.sh` or any current installer.
Do not run the archived bootstrap: its repository paths describe the old layout.

The obsolete iTerm2 preference export was removed when iTerm2 was retired.

Use the root README, `setup.sh`, `brew/Brewfile*`, and `scripts/` instead.
